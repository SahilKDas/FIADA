# FIADA Windows x64 Exoskeleton

Keep this entire directory together.

- `FIADA.exe` is the only executable and contains the game and Skia renderer.
- The three DLLs are the MSYS2 UCRT64 C++ runtime.
- `assets/png` contains external runtime artwork.
- `licenses` contains FIADA and redistributed dependency licenses.
- `SOURCE_COMMIT.txt` identifies the source revision.
- `SHA256SUMS.txt` covers every other packaged file.

Double-click `FIADA.exe`. Hold Space while sliding to charge a mini-turbo,
then release it. This package is unsigned; do not disable antivirus protection.
